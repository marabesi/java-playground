# java-playground

A safe playground for exploring the Java ecosystem, including frameworks, language features, and experimentation with various Java technologies.

## Purpose

This repository serves as a sandbox environment for learning and experimenting with:

- Java language features and updates: Exploring new Java versions, modern syntax, pattern matching, records, sealed classes, and evolving language capabilities
- Popular frameworks (Spring Boot, Micronaut, etc.): Hands-on experience with enterprise frameworks, understanding their conventions, architectural patterns, and ecosystem
- Reactive programming with Java: Experimenting with reactive streams, Project Reactor, and asynchronous programming models
- Java modules system: Understanding JPMS (Java Platform Module System), module declarations, dependencies, and encapsulation
- Build tools and project structures: Working with Gradle, Maven, and various project organization strategies
- Testing and development practices: Trying different testing frameworks, TDD approaches, and development workflows

## What's Inside

This repository contains several exploration areas:

- java-modules/: Examples with the Java module system, multi-module projects, and visibility patterns
- spring-boot-playground/: Spring Boot applications exploring clean architecture and other patterns
- micronaut-playground/: Micronaut framework experiments with compile-time DI and microservices
- reactive-java/: Reactive programming examples using Project Reactor

## Philosophy

This is a learning space where mistakes are part of the process. The code quality varies intentionally—the focus is on exploration and understanding, not production-ready code. Each experiment teaches something new about the Java ecosystem.

Feel free to explore, break things, and learn without fear!
